# مدرسة خالد سليمان الإعدادية — الهوية الزجاجية

تطوير داخل مشروع Next.js الأصلي، انطلاقًا من التعديل a7d8690. هوية عربية فاتحة للصفوف السابع–التاسع، ورسومات زجاجية ومجلة ومختبر مجسّمات تفاعلي.

## التشغيل

يتطلب Node.js 22.6 أو أحدث.

```sh
npm ci
npm run dev
```

يفتح الموقع على http://localhost:3000. لبناء نسخة التشغيل:

```sh
npm run build
npm start
```

في بيئات Windows المقيّدة، إذا ظهر EPERM أثناء إنشاء مجلدات البناء:

```sh
npm run build:windows
npm start
```

الأمر البديل ينظّف مجلد البناء المولّد .next فقط، ويجهّز مجلداته بالتتابع قبل البناء. لا يغيّر المصدر أو الصور. يمكن فصل معاينة التطوير عن البناء بتعيين NEXT_DIST_DIR=.next-preview؛ وتجب إعادة تعيين القيمة نفسها عند تشغيل البناء الناتج. لا تشغّل dev وbuild على مجلد الإخراج نفسه.

## ما تغيّر

- الرئيسية والقائمة والتذييل ونظام البطاقات والأزرار والصفحات الداخلية بالهوية الفاتحة المعتمدة.
- عشر رسومات زجاجية أصلية في مواضعها، مع ألوان الصفوف: السابع سماوي، الثامن بنفسجي، التاسع برتقالي.
- /articles: مجلة آفاق، بحث عربي، 11 تصنيفًا، تحميل المزيد، وقائمة قراءة محفوظة على الجهاز.
- /articles/[slug]: 44 مقالًا كاملًا، مع أغلفة متجاوبة، أنشطة، أسئلة، مصادر، مقالات مرتبطة وتسعة رسوم قابلة للتكبير.
- /discover: خمسة مجسّمات Three.js تُحمّل عند الطلب. تدوير بالأزرار والسحب، تشغيل وإيقاف، واحترام تقليل الحركة. الصور الثابتة بديل عند تعذّر WebGL.
- التمييز الواضح بين المحتوى التجريبي والبيانات المعتمدة؛ منع تصدير المواعيد التجريبية أو نشر أخبارها على الشبكات الاجتماعية.
- تصحيح نماذج المشاركة لتعرض معاينة صادقة؛ لم تعد تزعم إرسال بيانات دون خادم.
- تصحيح فلاتر الرزنامة لتجمع النوع والصف، واستبدال نموذج mailto الفارغ بحالة واضحة.
- تحديث PostCSS عبر override متوافق مع Next 15، وإضافة قفل اعتماديات وفحوصات.

## ضوابط التصميم والمحتوى

الخلفية #F5F8FC، النص #10182F، النص الثانوي #53627A، الأزرق #2563EB، السماوي #06B6D4، البنفسجي #7C3AED، البرتقالي #EA580C. النصوص الصغيرة تستخدم درجات أغمق للتباين. خط Tajawal، واتجاه RTL دائم، دون التحول التلقائي إلى هوية داكنة.

الأغلفة WebP بعروض 480 و800 و1600، والأبعاد 16:9. صور المقالات مولدة وليست توثيقًا لطلاب أو أحداث المدرسة. صور الأشخاص من النسخة المصححة V3/V4؛ لا تُرجع الصور التي تركز على شخصين. رمز الكتاب في الواجهة وأيقونة الاختصار عنصر واجهة مؤقت، وليس الشعار الرسمي.

المقالات تتضمن الإسناد إلى إعداد بمساعدة الذكاء الاصطناعي، ومصادرها وأنشطتها. لا تُخترع أسماء كُتّاب أو تواريخ نشر أو عدادات إعجاب. المقالات الإسلامية ضمن التربية الإسلامية؛ لم تغيّر نصوصها أو مراجعها أثناء الدمج.

الرسومات الثلاثية الأبعاد في الرئيسية صور ثابتة. المجسّمات الحقيقية تعمل داخل المختبر عند الطلب، وهي تعبيرية وليست محاكاة علمية دقيقة.

## البيانات التي تنتظر المدرسة

الشعار والصور الحقيقية، بيانات التواصل، كلمة المديرة وأسماء الطاقم والشعب، والأخبار والإعلانات والمواعيد المعتمدة. البيانات الحالية التي تحمل sample: true للتجربة فقط. أزل العلامة فقط بعد استبدال السجل بمحتوى حقيقي معتمد.

لا توجد قاعدة بيانات لمشاركات الطلاب أو تجميع الأصوات. المشاركات معاينة داخل الصفحة، والتصويت والمقالات المحفوظة والتقدّم في التحديات على المتصفح فقط. حفظ المقالات عبر ks-school-reading-list-v1. لا تُرسل نتائج أسئلة المقالات.

## رابط الموقع النهائي والفهرسة

إعداد واحد يتحكّم بالنشر لمحركات البحث: `SITE_URL` (مثال: `https://school.example`). يُقرأ وقت البناء، فبعد تغييره أعد البناء.

- **فارغ (الوضع الحالي):** الصفحات تحمل `noindex`، و`/robots.txt` يمنع الزحف، و`/sitemap.xml` فارغة.
- **معبّأ:** تُفتح الفهرسة (عدا `/admin` و`/login` و`/api/`)، وتُنشأ خريطة الموقع للصفحات والمقالات والتحديات والنشرات والأخبار غير التجريبية، وتصبح صور المشاركة روابط كاملة.

## التحقّق

```sh
npm run typecheck
npm test
npm run build
node scripts/smoke.mjs http://127.0.0.1:3000
npm audit --omit=dev
```

smoke يحتاج خادمًا محليًا يعمل. يفحص 75 صفحة و151 أصلًا، وRTL والعنوان الرئيسي، وحجب النشر دون تصريح، واستبعاد المواعيد التجريبية من التقويم، وحالة 404. راجع VERIFICATION-AR.txt لتفاصيل الاختبارات الفعلية وحدودها.

## ربط النشر الاجتماعي لاحقًا

إعدادات Meta تبقى في متغيرات البيئة الخادمية حسب .env.example. لا تضع رموز الوصول في الملفات العامة أو المقالات. مسار POST /api/social/publish يتطلب ADMIN_TOKEN، ويرفض الأخبار التجريبية والبيانات غير الصالحة. لم يُختبر نشر حقيقي ولم تُرسل منشورات خلال هذا العمل. صفحة /admin ليست نظام إدارة محتوى أو مصادقة متكاملًا.
