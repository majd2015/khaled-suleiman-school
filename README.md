# موقع مدرسة خالد سليمان الإعدادية

موقع المدرسة (الصفوف السابع حتى التاسع)، مبني على هيكل موقع مدرسة مشيرفة الإعدادية مع تصميم مختلف.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## أين أعدّل؟

| ماذا | الملف |
|---|---|
| اسم المدرسة، الهواتف، العنوان، روابط فيسبوك وإنستجرام، القائمة | `site.config.ts` |
| الأخبار، الإعلانات، الصفوف والشعب، الرزنامة، التحديات، النشرة | `content/data.ts` |
| الألوان والخطوط | `app/globals.css` (أعلى الملف) |
| الشعار | `public/logo.svg` |

كل قيمة مكتوب فيها "بانتظار بيانات المدرسة" تنتظر معلومات من المديرة.

## الأقسام

الرئيسية، عن المدرسة (نبذة، كلمة المديرة، الرؤية، الدستور، الطاقم، اتصل بنا)، الصفوف (صفحة لكل صف مع الشعب والإعلانات والمواعيد والتحديات والأخبار)، الأخبار (تصنيفات وترقيم صفحات)، الإعلانات، الرزنامة (فلترة حسب النوع والصف، وتصدير إلى تقويم الهاتف `/calendar.ics`)، النشرة الشهرية، تحدَّ نفسك، شارك (المناظرة، التصويت، الكلمة الطيبة، نادي القراءة)، تثبيت التطبيق (PWA)، الخصوصية، ولوحة النشر `/admin`.

## النشر التلقائي على فيسبوك وإنستجرام

يعمل بالاتجاهين:
- **من الموقع إلى فيسبوك وإنستجرام:** من لوحة `/admin`.
- **من فيسبوك إلى الموقع:** منشورات صفحة المدرسة تظهر تلقائيًا في الأخبار (تتحدّث كل 15 دقيقة). المنشورات التي نشرها الموقع نفسه تُتجاهل حتى لا يتكرر الخبر.

1. حساب إنستجرام المدرسة يجب أن يكون حساب أعمال (Business) ومربوطًا بصفحة الفيسبوك.
2. ننشئ تطبيق Meta ونأخذ Page Access Token طويل الأمد بصلاحيات `pages_manage_posts`, `instagram_basic`, `instagram_content_publish`.
3. نضع القيم في متغيرات البيئة (انظر `.env.example`).
4. من `/admin` نختار الخبر ونضغط "انشر"، أو نرسل `POST /api/social/publish`.

إنستجرام يشترط صورة لكل منشور.

## المرحلة القادمة

- قاعدة بيانات ولوحة إدارة لإضافة الأخبار والإعلانات من المتصفح، مع نشر تلقائي عند الحفظ.
- حفظ مشاركات الطلاب للمراجعة قبل النشر، وتجميع نتائج التصويت.
