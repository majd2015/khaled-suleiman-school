هذه نسخة تنفيذية مطوّرة من مشروع مدرسة خالد سليمان الإعدادية، وليست خطة أو صورًا منفصلة. ابدأ من المصدر الموجود في هذه الحزمة، واقرأ README.md وVERIFICATION-AR.txt قبل تعديلها.

قرار التصميم المعتمد من صاحب المشروع
هوية فاتحة زجاجية بروح الصورة السادسة التي اختارها: خلفية #F5F8FC، نص #10182F، نص ثانوي #53627A، أزرق #2563EB، سماوي #06B6D4، بنفسجي #7C3AED وبرتقالي #EA580C. بطاقات مستديرة شفافة بخفة، حواف فاتحة وظلال ناعمة، وعناصر ثلاثية الأبعاد واضحة. الخط Tajawal واتجاه RTL. لا تعُد إلى الأخضر والذهبي السابقين أو النيون الداكن، ولا تحوّل الهوية تلقائيًا مع تفضيل الجهاز للوضع الداكن.

ما هو مدمج بالفعل
الرئيسية والقائمة والتذييل والصفوف والصفحات الداخلية، مجلة آفاق بـ44 مقالًا كاملًا، أغلفة WebP بثلاثة أحجام، أنشطة وأسئلة ومصادر ورسوم تعليمية، البحث والتصنيف وقائمة القراءة، ومختبر بخمسة مجسّمات حقيقية. لا تعِد استيراد دفعات V1/V2/V3/V4؛ source of truth هو content/articles.json، والمطابقة عبر slug. لا تُرجع صور الأشخاص التي تركز على شخصين؛ استُخدمت النسخة المصححة المعتمدة.

الحفاظ على الشكل
اعتمد brand.ts وapp/globals.css ومكونات components/articles/ وتنسيق app/articles/articles.css. حافظ على نسب الأغلفة 16:9 وأحجامها المتجاوبة، الفراغات، خطوط العناوين، ألوان التصنيفات، تدرّج الأزرار، وحالات التركيز. استعمل البطاقات الحالية بدل بناء نظام بطاقات ثانٍ. راجع لقطات preview والصفحة العاملة قبل وبعد أي تغيير على الهاتف والكمبيوتر.

المجسّمات
رسمة الرئيسية صورة ثابتة ذات مظهر ثلاثي الأبعاد. المجسّمات التفاعلية في /discover تُحمّل عند طلب المستخدم فقط. احتفظ بتنظيف موارد Three.js، والتحكم بالأزرار والسحب، وإيقاف الحركة والبديل الثابت. لا تشغّل خمسة مشاهد WebGL تلقائيًا في الرئيسية.

الوظائف والبيانات
الشعار الحالي رمز واجهة مؤقت. استبدله بالشعار الرسمي عند وصوله. استبدل البيانات التجريبية في content/data.ts ببيانات معتمدة فقط ثم أزل sample: true عن السجلات الصحيحة. بيانات التواصل في site.config.ts. لا تخترع أسماء كُتّاب أو أرقام تفاعل أو أخبار مدرسة حقيقية. لا تعرض نجاح إرسال قبل ربط قناة استقبال فعلية. حفظ المقالات محلي؛ ليس حساب طالب أو خدمة تزامن. إبقِ مصدر الصور المولدة واضحًا.

التشغيل والدمج
هذه حزمة مصدر Next.js كاملة دون node_modules أو ملفات البناء أو الأسرار. استخدم npm ci ثم npm run dev. ابنِ باستخدام npm run build؛ في Windows المقيّد استخدم npm run build:windows عند مشكلة EPERM. شغّل npm run typecheck وnpm test وفحص smoke مع خادم يعمل. الحزمة ليست موقعًا منشورًا، ولم تُدفع تغييراتها إلى GitHub. ادمجها في فرع مراجعة يحافظ على أي تعديلات أحدث في المستودع بدل الكتابة فوقها بلا مقارنة.

المطلوب لاحقًا
اعتماد بيانات المدرسة والشعار والمحتوى الحقيقي، وربط خدمات الإرسال والإدارة فقط عند توفر متطلباتها. حافظ على الشكل الحالي عند تنفيذ ذلك، وقدّم معاينة فعلية وأعد الفحوص بعد أي تغيير وظيفي.
